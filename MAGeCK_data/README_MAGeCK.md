# MAGeCK analysis

Run the R scripts from the manuscript project root. Input preparation uses
`data.table`; postprocessing also uses `openxlsx`, `ggplot2` and `scales`.
The supplied MAGeCK version record is 0.5.9.5.

## Inputs and sample names

Script 01 reads the batch count tables and experimental designs in
`Barcode_counting/count_tables/`, plus `annotation_input/PAO1_key.tsv`.
`sample_name_map.tsv` matches original sample IDs, with or without batch
prefixes, to the 40 deposited GEO labels, such as `B4_01_T1_MH`.
Both counts and designs are mapped before matching; upstream files are not
rewritten. Comparison IDs such as `TOB_1_T1_vs_None_0_T1` identify statistical
contrasts and are retained for downstream compatibility.

## Run

Prepare count matrices, manifests and shell commands in R/RStudio:

```r
source("MAGeCK_data/01_MAGeCK_preprocessing_and_run.R")
```

For a new statistical run, activate your MAGeCK environment and run:

```bash
conda activate mageckenv
bash MAGeCK_data/mageck_rra_raw_AG/run_all_MAGeCK_RRA.sh
```

Then import results and generate QC tables in R/RStudio:

```r
source("MAGeCK_data/02_MAGeCK_postprocessing.R")
```

When updating sample labels only, the supplied count values, sample order and
treatment/control assignments are unchanged. Retain the gene summaries and
run the two R steps; repeating MAGeCK testing is unnecessary for that update.
The postprocessor groups replicates from either original or GEO-style IDs.

The primary runner contains 19 tests: seven treatment/control comparisons,
five untreated post/T0 comparisons and seven treated/T0 comparisons.
It uses full-match targeting guides, median normalization and median gene LFC.
The separate B4 TOB1 `TOTALNORM.gene_summary.txt` is required by postprocessing
for its existing recurrence check; it is retained and is not generated by the
19-test runner. Rerunning scripts can replace generated files.

## Retaining inputs and results

Keep both R scripts, `sample_name_map.tsv`, the four full-match count matrices,
the combined preprocessing manifest, version/settings records and all 20
`*.gene_summary.txt` files, including TOTALNORM. These support postprocessing
without repeating MAGeCK testing. Keep the generated shell runners for reruns.

The downstream S7/S8 workflow uses these files in
`mageck_rra_postprocessing_AG/`:

- `MAGeCK_drug_contrasts_all_genes.tsv.gz`
- `MAGeCK_T1_AG_recurrence_drug_contrasts_all_genes.tsv.gz`
- `MAGeCK_contrast_manifest.tsv`
- `MAGeCK_analysis_settings.tsv`

Other generated postprocessing tables and plots can be rebuilt with script 02.
The optional T0-filter status tables, unknown-spacer audit tables, run logs
and generated `QC/` folder are not required to execute the two R scripts.
